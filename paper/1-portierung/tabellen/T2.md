**T2.** Implementation artefacts of the original and the switches that turn them off (ADR 0015). The modern mode switches all of them off.

| Switch | Artefact |
|---|---|
| no_display_side_effects | The value display at the end of a cycle computes `EpiKomp` for all needs, which draws random numbers, reinforces goal links and advances age (ADR 0011). |
| clean_direction_names | `DirArtWert` reads the third letter of `lN`/`lS` from left-over memory (stack residue in `ContinueDirection`, a heap address byte in `RememberDir`, ADR 0014). |
| goal_in_current_situation | `PlanenUndTun`'s parameter `situation` shadows the global `Situation`: after a plan with a locomotion, the goal is looked for in the old situation. |
| aversion_check_in_aversions | `Consum` checks whether an aversion is known in the goal list (`toGoal`) and links `toAvers`; a known aversion is therefore never reinforced. |
| background_goals_as_described | `GoalGen` takes a background goal if `random < r - s` with `s = r - strength * threshold`, which reduces to `random < strength * threshold`: the stronger the current motive, the more background goals. |
| guard_nil_dereferences | The original follows pointers without checking for nil in several places (e.g. `ActivateAuto` walking a protocol chain that ends early). |
| real_umlaut_bitmaps | Under Wine the original does not find the bitmap files with an umlaut and draws their names as text (ADR 0013). |
